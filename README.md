###### Descrição do Projeto
_Projeto feito para Auxiliar tecnicos de Campo que instalam roteadores Wifi6  que por padrao vem com a Rede Wifi Unificada, 
visto que por vezes a rede unificada não funciona tão bem com dispositivos mais antigos ou cameras wifi_
* O aplicativo faz a leitura do gateway na placa de rede do celular usuario só digita a senha do Roteador pra acessar
* Aplicativo da a Opção de Separar as Redes ou somente configurar o SSID e PASSWORD
* Possivel testar a velocidade via wifi , aplicativo possui um webview mostrando o site Fast.com
